# Privacy-Preserving Healthcare Data Processing Using Homomorphic Encryption

A privacy-focused healthcare data management system that enables hospitals to securely manage patient records and process large datasets using batch processing, AES encryption, and BFV homomorphic encryption.

## Key Features

- Hospital registration with secret-key-based authentication and hospital-specific dashboards.
- Upload and process large patient datasets through CSV files.
- Batch-wise processing and transmission of large healthcare datasets for efficient handling of high-volume data.
- Add, update, and delete individual patient records.
- AES and BFV homomorphic encryption for protecting sensitive healthcare data.
- Encrypted data storage in Supabase PostgreSQL.
- Hospital-specific data isolation to prevent unauthorized access across hospitals.
- Secret-key-based access to authorized data operations and decryption.

## Tech Stack

- **Programming Language:** Python
- **Homomorphic Encryption:** TenSEAL, BFV
- **Encryption:** AES, BFV Homomorphic Encryption
- **Database:** Supabase PostgreSQL
- **Backend / Application:** Python
- **Version Control:** Git, GitHub
